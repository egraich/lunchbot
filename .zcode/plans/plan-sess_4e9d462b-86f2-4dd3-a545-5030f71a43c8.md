# TG-бот «Meal Tracker» — план реализации

Проект создаётся в текущей папке `D:\VS Projects\Python Projects\Launch_tracker` (она пустая — это наш корень).

## 1. Ключевое решение: О(1), а не Ос1

Выбираю **О(1)**: (а) на твоём же фото классрук уже читает таблицу с «О(1)» — формат менять никто не должен; (б) короче, не разъезжается в узких клетках; (в) читается как модификатор к «О» (обед + 1 блюдо), а «Ос1» выглядит как опечатка. В БД храним ASCII-коды `O` и `O1`, в Excel рендерим `О` / `О(1)`, в Telegram — ✅ / 🍜.

## 4. Схема БД (meal_tracker.db)

- `schools(id, name UNIQUE)` — «Гимназия» и т.д.
- `admins(telegram_id PK, school_id→schools, class_name, added_by, created_at)` — 1 админ = 1 класс; на один класс можно добавить несколько админов (запасной). Суперадмины — только из `.env` (`SUPERADMIN_IDS`).
- `students(id, school_id, class_name, name, position, is_active)` — порядок = порядок в доске и Excel.
- `records(student_id, date 'YYYY-MM-DD', status 'O'|'O1', PK(student_id, date))` — «не ест» = нет записи (пустая клетка).
- `board_sessions(telegram_id, date, chat_id, message_id, status 'open'|'confirmed'|'skipped')` — чтобы не задублировать утреннюю рассылку и уметь `/today`.
- `settings(telegram_id PK, morning_time '07:40', excel_enabled 0, excel_day 'last', excel_time '16:00', excel_last_sent)`.
- `auto_skip(student_id, weekday 0–6, UNIQUE)` — авто-❌ по дням недели.

## 5. Утренняя доска (ядро бота)

В 7:40 (по Minsk, пн–пт) каждому админу — сообщение с клавиатурой:

```
[          ❌ НЕ ЗАПИСЫВАТЬ ❌          ]   ← весь день пропустить (праздник)
[Климович И ❌] [🍜] [✅]                  ← дефолт: не ест (пустая клетка)
[❌] [Старик Ф 🍜] [✅]                    ← имя «мигрирует» на нажатую кнопку
[❌] [🍜] [Бабчук Г ✅]
…
[🔄 Рестарт] [Подтвердить ✅]
```

- Состояние доски **не хранится отдельно** — парсим `reply_markup` текущего сообщения, применяем переключение, пересобираем клавиатуру и `edit_message_reply_markup`. Переживает рестарты бота.
- Повторный клик по уже выбранной кнопке → сброс на ❌. Имя всегда сидит на выбранной кнопке, эмодзи справа от имени; остальные кнопки ряда — чистый эмодзи. Длина рядов не «прыгает».
- Авто-пропуск (по правилам дня недели): ряд есть, но одна зажатая кнопка `[Имя ❌]` без выбора — как ты и просил.
- Callback data: `m:{date}:{student_id}:{act}` (act: `x|o|o1`), day-уровень: student_id=0, act: `skip|restart|confirm` — влезает в 64 байта.
- **Подтвердить** → апсерт `records`, session=confirmed, сообщение превращается в итог: «Записано (24.09, 11-Б):» и список всех учеников `Имя Ф — ❌|✅|🍜`. Повторные клики после подтверждения игнорируются с alert «открой заново через /today».
- **НЕ ЗАПИСЫВАТЬ** → session=skipped, сообщение «День не записываем», внизу кнопка Рестарт на случай промаха.
- **Рестарт** → клавиатура с нуля (авто-пропуска применяются заново).
- **/today** — открыть/переоткрыть доску на сегодня (после подтверждения подхватывает уже записанные `records` — можно исправить и подтвердить повторно).

## 6. /management (инлайн-меню)

- ⏰ **Время утренней рассылки** — пресеты (07:30/07:40/07:50…) + ввод `ЧЧ:ММ` через FSM.
- 🙈 **Авто-пропуск** — выбор дня недели → список класса с toggle (ученик + будний день = авто-❌).
- 🧑‍🎓 **Ученики** — добавить (FSM: Фамилия И, по одному), удалить, переименовать, поменять порядок (кнопки ↑/↓).
- 📊 **Авто-Excel** — вкл/выкл, день месяца (по умолчанию последний день), время; отчёт приходит **только админу** (решено), дальше сам пересылаешь классруку.
- 📤 **Отчёт сейчас** — выбор месяца → сгенерировать и прислать xlsx немедленно.
- ❓ **Гайды** — краткая инструкция по каждому сценарию.

## 7. Excel (формат ровно как на фото)

openpyxl: строка 1 — `Сентябрь:` (bold italic) + числа всех **пн–пт** месяца; строки учеников — `О` / `О(1)` / пусто; внизу `Без первого :` и `С первым :` — автоподсчёт за каждый день; границы, ширина колонок. Файл `11-Б_2026-09.xlsx` как документ. Авто-отправка: тик-джоб проверяет день/время и `excel_last_sent` (защита от дублей), шлёт админу.

## 8. Планировщик

Один тик каждую минуту в Europe/Minsk: для каждого админа — если будний день, `now >= morning_time`, сессии на сегодня нет → отправить доску (если бот был выключен в 7:40, доска придёт при старте — не потеряется). Тот же тик раздаёт авто-Excel. Суббота/воскресенье — тишина.

## 9. Суперадмин

`/add 123456789 11-Б Гимназия` (школа может быть из нескольких слов), `/del 123456789`, `/admins`. Проверка ID по `SUPERADMIN_IDS` из `.env`. `.env.example`: `BOT_TOKEN`, `SUPERADMIN_IDS=id1,id2`, `TZ=Europe/Minsk`, `DB_PATH`.
